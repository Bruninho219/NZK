Comandos do NZK

Consulte os comandos disponíveis no Discord, seus parâmetros e quem pode utilizá-los. O NZK usa comandos híbridos: a maioria pode ser executada tanto como slash command quanto pelo prefixo tradicional.

Como usar: prefira o formato slash, por exemplo /nrank. O formato tradicional também continua disponível, como !nRank. Parâmetros entre [colchetes] são opcionais.

👤 Comandos de usuário

Podem ser usados pelos membros do servidor.

/nrank
Usuário
Mostra nível, XP, posição no ranking, mensagens, tempo em voz e reações do membro.
Slash: /nrank [target]
Prefixo: !nRank [@usuário]
Exemplo: /nrank @Bruno
/ntop
Usuário
Exibe os cinco membros mais bem colocados no ranking do servidor.
Slash: /ntop
Prefixo: !nTop
/nconquistas
Usuário
Lista as conquistas já desbloqueadas pelo próprio usuário ou por outro membro.
Slash: /nconquistas [target]
Prefixo: !nConquistas [@usuário]
/nhistorico
Usuário
Mostra o histórico de XP do usuário em formato de tabela, respeitando o período disponível no plano do servidor.
Slash: /nhistorico [target]
Prefixo: !nHistorico [@usuário]
/nhistorico2
Usuário
Gera um gráfico com o histórico de XP registrado nos últimos 30 dias.
Slash: /nhistorico2 [target]
Prefixo: !nHistorico2 [@usuário]
/nping
Usuário
Mostra a latência atual da conexão do bot com o Discord.
Slash: /nping
Prefixo: !nPing
/nping2
Usuário
Mede o tempo de resposta de uma mensagem e também informa a latência do gateway.
Slash: /nping2
Prefixo: !nPing2
/ninfo
Usuário
Exibe informações gerais do NZK, incluindo versão, latência e autoria.
Slash: /ninfo
Prefixo: !nInfo
/nhelp
Usuário
Exibe dentro do Discord um resumo dos principais comandos disponíveis.
Slash: /nhelp
Prefixo: !nHelp

🔧 Comandos administrativos

Exigem permissão administrativa no servidor ou acesso de proprietário do bot.

/nadmin
Admin
Mostra um resumo das configurações administrativas do servidor.
Slash: /nadmin
Prefixo: !nAdmin
/nbonus
Admin
Consulta ou altera o bônus percentual de XP para boosters e administradores.
Slash: /nbonus [tipo] [valor]
Prefixo: !nBonus booster 10
Tipos: booster ou admin
/nbonusstack
Admin
Define se os bônus de administrador e booster serão somados ou se apenas o maior será aplicado.
Slash: /nbonusstack valor
Prefixo: !nBonusStack sim
Valores: sim ou nao
/nreset
Admin
Reseta a progressão de um membro ou, sem usuário informado, de todo o servidor.
Slash: /nreset [target]
Prefixo: !nReset [@usuário]
Atenção: sem usuário, o reset total exige confirmação.
/nsetxp
Admin
Define manualmente o XP atual de um membro.
Slash: /nsetxp target valor
Prefixo: !nSetXP @usuário 500
/nsetlevel
Admin
Define manualmente o nível de um membro. Ao alterar o nível, o XP atual é zerado.
Slash: /nsetlevel target valor
Prefixo: !nSetLevel @usuário 5
/nfix
Admin
Revisa os membros do servidor e corrige os cargos de patente de acordo com o nível atual.
Slash: /nfix
Prefixo: !nFix
/nsync
Admin
Sincroniza cargos, canais e administradores do Discord com os dados usados pelo painel.
Slash: /nsync
Prefixo: !nSync
/nsync2
Admin
Atualiza os nomes de exibição das patentes usando os cargos sincronizados do servidor.
Slash: /nsync2
Prefixo: !nSync2
/nstatus
Admin
Aplica imediatamente no Discord o status global configurado para o bot.
Slash: /nstatus
Prefixo: !nStatus
/setchannel
Admin
Define o canal atual como canal de avisos do servidor.
Slash: /setchannel
Prefixo: !setchannel
